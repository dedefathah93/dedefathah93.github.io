Swift adalah bahasa pemrograman yang
digunakan untuk membangun aplikasi
pada ekosistem Apple.

## Variable dan Constant

Dalam Swift, let digunakan untuk
mendeklarasikan constant.

```swift
let nama = "Budi"
var umur = 20
```

## Kesimpulan

let digunakan ketika nilai tidak perlu diubah setelah diinisialisasi.

var digunakan ketika nilainya perlu diubah.
