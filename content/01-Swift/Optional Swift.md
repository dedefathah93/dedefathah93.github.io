
# Memahami Optional dalam Swift

Optional digunakan ketika sebuah nilai
mungkin tersedia atau bernilai nil.

## Contoh

```swift
var nama: String? = nil
nama = "Budi"
```

## Hal yang perlu saya ingat

- String dan String? adalah tipe yang berbeda.
- Optional perlu ditangani sebelum nilainya
  digunakan pada operasi yang membutuhkan
  nilai non-optional.
- Salah satu caranya menggunakan if let.
