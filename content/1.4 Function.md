Nomor 12 sampai 17 semuanya berkaitan dengan satu konsep.
```
func calculateTotal(
    prices: [Int]
) -> Int {
```

Baca dari kiri ke kanan:
```
func
↓
saya membuat function

calculateTotal
↓
nama function

prices: [Int]
↓
function menerima Array berisi Int

-> Int
↓
function mengembalikan Int
```

Jadi:
```
calculateTotal(
    prices: [10_000, 25_000, 5_000]
)
```

input:
```
10.000
25.000
5.000
```

Function menjumlahkannya.

Output:
```
40.000
```

Jadi:
```
let result = ...
```

akhirnya:
```
result = 40.000
```

Nanti ini sangat penting karena hampir seluruh aplikasi terdiri dari function.

Contoh:
```
login()
loadStudents()
saveAttendance()
deleteTransaction()
sendMessage()
```

---
Function pada dasarnya adalah blok kode yang diberi nama agar bisa dipanggil berulang kali.

Contoh:

```
func greet() {
    print("Halo")
}
```

Di sini kita mendefinisikan function bernama:

```
greet
```

Function itu belum berjalan ketika dibuat.

Baru berjalan saat dipanggil:

```
greet()
```

Output:

```
Halo
```

Sekarang function yang menerima data:

```
func greet(name: String) {
    print("Halo \(name)")
}
```

Dipanggil:

```
greet(name: "Dede")
```

Output:

```
Halo Dede
```

`name` disebut parameter.

Secara konsep:

```
input
↓
function
↓
proses
```

Sekarang function yang mengembalikan nilai:

```
func calculateTotal(
    price: Int,
    quantity: Int
) -> Int {
    return price * quantity
}
```

Bagian:

```
-> Int
```

berarti function mengembalikan `Int`.

Dipanggil:

```
let total = calculateTotal(
    price: 500_000,
    quantity: 2
)
```

Maka:

```
total = 1.000.000
```

Alurnya:

```
500.000
2
↓
calculateTotal
↓
500.000 × 2
↓
1.000.000
↓
return
↓
total
```

Sekarang perhatikan function ini:

```
func isPassed(score: Int) -> Bool {
    return score >= 75
}
```

Kalau:

```
let result = isPassed(score: 80)
```

hasil:

```
true
```

Kalau:

```
let result = isPassed(score: 60)
```

hasil:

```
false
```

Sekarang ada satu hal penting.

Function bisa menerima banyak parameter:

```
func createStudent(
    name: String,
    score: Int,
    className: String
) {
    print(name)
    print(score)
    print(className)
}
```

Dipanggil:

```
createStudent(
    name: "Dede",
    score: 90,
    className: "10.2"
)
```

Function juga bisa tidak mengembalikan nilai sama sekali.

Contoh:

```
func printStudent(name: String) {
    print(name)
}
```

Karena tidak ada:

```
-> ...
```

Function hanya melakukan tindakan.

Bandingkan:

```
func printStudent(name: String) {
    print(name)
}
```

dengan:

```
func getStudentName(name: String) -> String {
    return name
}
```

Yang pertama melakukan sesuatu.

Yang kedua menghasilkan nilai.

Sekarang kita masuk ke local variable.

```
func calculateDiscount(
    price: Int,
    discount: Int
) -> Int {
    let discountAmount = price * discount / 100
    let finalPrice = price - discountAmount

    return finalPrice
}
```

`discountAmount` dan `finalPrice` hanya hidup di dalam function tersebut.

Ini disebut scope.

Di luar function, Anda tidak bisa langsung menggunakan:

```
discountAmount
```

karena variable itu hanya dikenal di dalam function.
