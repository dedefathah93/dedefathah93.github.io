## Hari 4 Bagian 1, Array

Misalnya kita punya satu nama siswa:

```

```

```
let student1 = "Ahmad"
let student2 = "Rina"
let student3 = "Dede"
```

Tetapi jelas tidak efisien.

```
Array
```

```
let students = [

    "Dede"

```

```
students
```

Secara konsep:

```
students

[2] Dede
```

```
0
```

Jadi:

```

```

```
students[1]
```


```
students[2]
```

```

```

Ini konsep penting.

## Tipe Array

Swift sangat peduli dengan tipe data.

Array ini:

```
let students: [String] = [
    "Ahmad",
    "Rina",
    "Dede"
]
```

berarti:

```
Array berisi String
```

Notasi:

```
[String]
```

dibaca:

> Array of String.

Contoh lain:

```
let scores: [Int] = [
    80,
    90,
    75
]
```

berarti:

```
Array of Int
```

Kita biasanya tidak perlu menulis tipenya secara eksplisit karena Swift bisa melakukan type inference:

```
let scores = [80, 90, 75]
```

Swift tahu bahwa ini:

```
[Int]
```

Sama seperti yang sudah kita pelajari:

```
let score = 80
```

Swift tahu `score` adalah `Int`.

## Array dengan `let` dan `var`

Perhatikan:

```
let students = [
    "Ahmad",
    "Rina"
]
```

Karena menggunakan:

```
let
```

Array tersebut tidak bisa diubah.

Kita tidak boleh:

```
students.append("Dede")
```

Tetapi:

```
var students = [
    "Ahmad",
    "Rina"
]
```

boleh.

Misalnya:

```
students.append("Dede")
```

sekarang:

```
Ahmad
Rina
Dede
```

Jadi aturan `let` dan `var` tetap sama seperti sebelumnya.

```
let
→ value tidak boleh dimutasi

var
→ boleh dimutasi
```

## Bahaya index

Perhatikan:

```

    "Ahmad",
    "Rina",
    "Dede"
]
```

Valid:

```
students[0]
students[1]
students[2]
```

Tetapi:

```

```

akan crash.

Kenapa?

Ini salah satu alasan kita sering memakai loop atau method collection daripada mengakses index secara manual.

# Sekarang `for-in`

Misalnya:

```
let students = [
    "Ahmad",
    "Rina",
    "Dede"
]
```

Kita ingin print semua nama.

Bisa saja:

```
print(students[0])
print(students[1])
print(students[2])
```

Tetapi kalau ada 500 siswa?

Tidak mungkin.

Kita gunakan:

```
for student in students {
    print(student)
}
```

Baca seperti bahasa manusia:

> Untuk setiap `student` yang ada di dalam `students`, jalankan kode ini.

Alur:

```
students
↓
Ahmad
↓
print

Rina
↓
print

Dede
↓
print
```

Output:

```
Ahmad
Rina
Dede
```

`student` di sini adalah variable sementara.

Pada putaran pertama:

```
student = Ahmad
```

putaran kedua:

```
student = Rina
```

putaran ketiga:

```
student = Dede
```

Setelah loop selesai, function lanjut ke kode berikutnya.

## Loop dengan struct

Sekarang:

```
struct Student {
    let name: String
    let score: Int
}

let students = [
    Student(name: "Ahmad", score: 80),
    Student(name: "Rina", score: 90),
    Student(name: "Dede", score: 60)
]
```

Kita bisa:

```
for student in students {
    print(student.name)
}
```

Output:

```
Ahmad
Rina
Dede
```

Atau:

```
for student in students {
    print(student.score)
}
```

Output:

```
80
90
60
```

Atau:

```
for student in students {
    print("\(student.name): \(student.score)")
}
```

Output:

```
Ahmad: 80
Rina: 90
Dede: 60
```

## Menghitung total dengan loop

Ini kembali ke soal assessment pertama Anda.

```
let prices = [
    10_000,
    25_000,
    5_000
]
```

Kita ingin jumlah:

```
var total = 0

for price in prices {
    total += price
}
```

Mari kita bedah.

Awal:

```
total = 0
```

Loop pertama:

```
price = 10.000

total = 0 + 10.000
total = 10.000
```

Loop kedua:

```
price = 25.000

total = 10.000 + 25.000
total = 35.000
```

Loop ketiga:

```
price = 5.000

total = 35.000 + 5.000
total = 40.000
```

akhir:

```
total = 40.000
```

Sekarang Anda bisa melihat function assessment dulu:

```
func calculateTotal(
    prices: [Int]
) -> Int {
    var total = 0

    for price in prices {
        total += price
    }

    return total
}
```

Sekarang seharusnya jauh lebih mudah dibaca.

Artinya:

```
input
↓
Array of Int

[10000, 25000, 5000]

↓ loop

jumlahkan semuanya

↓ return

40000
```

## Operator `+=`

Kode:

```
total += price
```

sama dengan:

```
total = total + price
```

Contoh:

```
var total = 10

total += 5
```

hasil:

```
15
```

Demikian juga:

```
count += 1
```

sama dengan:

```
count = count + 1
```

Ini yang sebelumnya kita lihat di SwiftUI:

```
Button("Tambah") {
    count += 1
}
```

Sekarang Anda sudah tahu arti operasinya.

# Kesalahan umum

Misalnya:

```
for student in students {
    var presentCount = 0

    if student.present {
        presentCount += 1
    }
}
```

Ada masalah.

Kenapa?

Karena:

```
var presentCount = 0
```

dibuat ulang setiap loop.

Jadi:

```
loop Ahmad
count = 0
→ 1

loop Rina
count dibuat lagi = 0

loop Dede
count dibuat lagi = 0
→ 1
```

Kita tidak akan mendapatkan total akhir.

Yang benar:

```
var presentCount = 0

for student in students {
    if student.present {
        presentCount += 1
    }
}
```

Karena `presentCount` dibuat sebelum loop.

Ini kembali ke konsep:

```
scope
```

yang kita pelajari kemarin.

# Array + function

Sekarang kita gabungkan semuanya:

```
struct Student {
    let name: String
    let score: Int
}

func countPassedStudents(
    students: [Student]
) -> Int {

    var count = 0

    for student in students {
        if student.score >= 75 {
            count += 1
        }
    }

    return count
}
```

Perhatikan input:

```
students: [Student]
```

Artinya:

```
function menerima Array of Student
```

Output:

```
-> Int
```

Artinya:

```
function mengembalikan jumlah siswa yang lulus
```

Misalnya:

```
let students = [
    Student(name: "Ahmad", score: 80),
    Student(name: "Rina", score: 90),
    Student(name: "Dede", score: 60)
]
```

Kemudian:

```
let result = countPassedStudents(
    students: students
)
```

hasil:

```
2
```

Karena:

```
Ahmad = lulus
Rina  = lulus
Dede  = tidak
```
