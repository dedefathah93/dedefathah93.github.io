Misalnya kita mencari siswa berdasarkan ID.

```
struct Student {
    let id: Int
    let name: String
}
```

Kita punya:

```
let students = [
    Student(id: 1, name: "Ahmad"),
    Student(id: 2, name: "Rina"),
    Student(id: 3, name: "Dede")
]
```

Sekarang function:

```
func findStudent(
    id: Int
) -> Student? {

    for student in students {
        if student.id == id {
            return student
        }
    }

    return nil
}
```

Perhatikan outputnya:

```
-> Student?
```

Kenapa Optional?

Karena hasil pencarian ada dua kemungkinan:

```
Student ditemukan
atau
tidak ditemukan
```

Kalau:

```
let result = findStudent(id: 2)
```

hasilnya secara konsep:

```
Student(id: 2, name: "Rina")
```

Tetapi kalau:

```
let result = findStudent(id: 99)
```

hasilnya:

```
nil
```

Jadi:

```
Student?
```

berarti:

```
Student
atau
nil
```

Ini sangat umum.

Misalnya nanti Anda akan menemukan function seperti:

```
func findUser(id: Int) -> User?
func loadToken() -> String?
func selectedStudent() -> Student?
```

Sekarang kita gunakan `if let`:

```
if let student = findStudent(id: 2) {
    print(student.name)
} else {
    print("Siswa tidak ditemukan")
}
```

Output:

```
Rina
```

Kalau:

```
if let student = findStudent(id: 99) {
    print(student.name)
} else {
    print("Siswa tidak ditemukan")
}
```

Output:

```
Siswa tidak ditemukan
```

Sekarang satu hal penting.

Function boleh punya beberapa `return`.

Contoh:

```
func grade(score: Int) -> String {

    if score >= 90 {
        return "A"
    }

    if score >= 80 {
        return "B"
    }

    if score >= 70 {
        return "C"
    }

    return "D"
}
```

Kalau:

```
grade(score: 85)
```

alur:

```
85 >= 90?
tidak

85 >= 80?
ya
↓
return "B"
↓
function selesai
```

Swift tidak melanjutkan mengecek:

```
>= 70
```

karena sudah bertemu `return`.

Sekarang kita hubungkan ke aplikasi nyata.

Misalnya login:

```
func validateLogin(
    username: String,
    password: String
) -> String? {

    guard !username.isEmpty else {
        return "Username wajib diisi"
    }

    guard !password.isEmpty else {
        return "Password wajib diisi"
    }

    guard password.count >= 6 else {
        return "Password minimal 6 karakter"
    }

    return nil
}
```

Di sini output:

```
String?
```

artinya:

```
ada String
→ ada error

nil
→ tidak ada error
```

Misalnya:

```
let error = validateLogin(
    username: "dede",
    password: "123"
)
```

hasil:

```
"Password minimal 6 karakter"
```

Kalau:

```
let error = validateLogin(
    username: "dede",
    password: "123456"
)
```

hasil:

```
nil
```

Artinya valid.

Ini pola yang sangat sering digunakan.
