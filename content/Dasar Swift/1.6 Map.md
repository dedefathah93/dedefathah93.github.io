Misalnya kita punya:

```
struct Student {
    let name: String
    let score: Int
}

let students = [
    Student(name: "Ahmad", score: 80),
    Student(name: "Rina", score: 90),
    Student(name: "Dede", score: 60)
]
```

Tipe:

```
[Student]
```

Kita ingin hanya mengambil nama.

Dengan loop manual:

```
var names: [String] = []

for student in students {
    names.append(student.name)
}
```

hasil:

```
["Ahmad", "Rina", "Dede"]
```

Swift punya cara lebih ringkas:

```
let names = students.map { student in
    student.name
}
```

Hasilnya sama:

```
["Ahmad", "Rina", "Dede"]
```

`map` artinya secara sederhana:

> Ambil setiap item dari collection, ubah menjadi sesuatu, lalu hasilkan Array baru.

Alurnya:

```
[Student]
   ↓
map
   ↓
[String]
```

Jadi `map` tidak harus menghasilkan tipe yang sama.

Contoh lain:

```
let scores = students.map { student in
    student.score
}
```

hasil:

```
[80, 90, 60]
```

Tipe:

```
[Int]
```

Jadi:

```
[Student]
↓
map
↓
[Int]
```

Sekarang contoh transformasi.

```
let labels = students.map { student in
    "\(student.name): \(student.score)"
}
```

hasil:

```
[
    "Ahmad: 80",
    "Rina: 90",
    "Dede: 60"
]
```

`map` benar-benar mengubah setiap elemen.

Sekarang kita lihat closure-nya.

```
students.map { student in
    student.name
}
```

Bagian:

```
{ student in
    student.name
}
```

adalah closure.

Untuk sementara baca saja:

> Untuk setiap `student`, hasilkan `student.name`.

Nanti closure akan kita bahas lebih dalam.

Swift juga punya shorthand:

```
let names = students.map {
    $0.name
}
```

`$0` artinya item pertama yang diberikan closure.

Jadi ini:

```
students.map { student in
    student.name
}
```

sama konsepnya dengan:

```
students.map {
    $0.name
}
```

Untuk belajar awal, saya lebih suka Anda pakai versi panjang dulu karena lebih mudah dibaca.

Sekarang contoh nyata aplikasi transaksi.

```
struct Transaction {
    let title: String
    let amount: Int
}

let transactions = [
    Transaction(title: "Makan", amount: 50_000),
    Transaction(title: "Bensin", amount: 100_000),
    Transaction(title: "Internet", amount: 150_000)
]
```

Kita bisa:

```
let titles = transactions.map { transaction in
    transaction.title
}
```

hasil:

```
["Makan", "Bensin", "Internet"]
```

Atau:

```
let amounts = transactions.map { transaction in
    transaction.amount
}
```

hasil:

```
[50000, 100000, 150000]
```

Perhatikan satu hal penting.

`map` tidak mengubah Array asli.

```
let titles = transactions.map { ... }
```

`transactions` tetap:

```
[Transaction]
```

dan `titles` adalah Array baru:

```
[String]
```

Jadi:

```
transactions
tetap

map
↓
membuat hasil baru
```

Sekarang contoh sedikit lebih kompleks:

```
let doubledAmounts = transactions.map { transaction in
    transaction.amount * 2
}
```

hasil:

```
[100000, 200000, 300000]
```

`map` mengambil:

```
50.000
100.000
150.000
```

lalu masing-masing diubah menjadi:

```
100.000
200.000
300.000
```
