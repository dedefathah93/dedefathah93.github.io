Jawaban nomor 2 Anda sudah benar.
```
let name: String
```
berarti setelah `Student` dibuat, `name` tidak boleh diganti.

Sedangkan:
```
var score: Int
```
boleh berubah.

Misalnya:
```
var student = Student(
    name: "Dede",
    score: 70
)

student.score = 85
```
boleh.

Tetapi:
```
student.name = "Ahmad"
```
tidak boleh karena `name` adalah `let`.

Sekarang ada dua tingkat `let/var` yang perlu Anda bedakan.
Pertama:
```
struct Student {
    let name: String
    var score: Int
}
```
Ini menentukan apakah property di dalam Student boleh berubah.

Kedua:
```
var student = Student(...)
```
Ini menentukan apakah variable `student` boleh dimodifikasi.

Itulah alasan pertanyaan nomor 3 menggunakan:
```
var student
```
Bukan karena “Student pasti berubah”.

Lebih tepat:
> Karena kita memang akan mengubah `student.score`.

Kalau kita menulis:
```
let student = Student(
    name: "Dede",
    score: 70
)

student.score = 85
```
Swift akan menolak.
Walaupun `score` dideklarasikan dengan `var`.
Ini karakter penting dari `struct`.
