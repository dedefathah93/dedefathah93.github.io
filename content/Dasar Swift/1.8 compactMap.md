Ini bagian yang menghubungkan materi Array dengan Optional yang kita pelajari di Hari 2.

Misalnya:

```
let values: [String?] = [
    "Ahmad",
    nil,
    "Rina",
    nil,
    "Dede"
]
```

Perhatikan tipe:

```
[String?]
```

Artinya:

```
Array berisi Optional String
```

Setiap item bisa:

```
String
atau
nil
```

Kita ingin membuang semua `nil`.

Bisa secara manual:

```
var names: [String] = []

for value in values {
    if let value = value {
        names.append(value)
    }
}
```

Hasil:

```
["Ahmad", "Rina", "Dede"]
```

Swift mempunyai cara yang lebih ringkas:

```
let names = values.compactMap { value in
    value
}
```

Hasil:

```
["Ahmad", "Rina", "Dede"]
```

Dan tipenya berubah dari:

```
[String?]
```

menjadi:

```
[String]
```

Jadi mental model paling sederhana:

```
compactMap
→ melakukan transformasi seperti map
→ tetapi membuang hasil nil
```

Contoh lain:

```
let numbers = [
    "10",
    "20",
    "abc",
    "30"
]
```

Kita ingin mengubah semua String menjadi Int.

Swift menyediakan:

```
Int("10")
```

hasil:

```
10
```

Tetapi:

```
Int("abc")
```

hasil:

```
nil
```

Karena `"abc"` tidak bisa diubah menjadi angka.

Kalau kita:

```
let converted = numbers.map { value in
    Int(value)
}
```

hasilnya:

```
[
    Optional(10),
    Optional(20),
    nil,
    Optional(30)
]
```

Secara tipe:

```
[Int?]
```

Tetapi kalau:

```
let converted = numbers.compactMap { value in
    Int(value)
}
```

hasilnya langsung:

```
[10, 20, 30]
```

tipe:

```
[Int]
```

`"abc"` hilang karena menghasilkan `nil`.

Jadi:

```
map
String
↓
Int?
↓
[Int?]

compactMap
String
↓
Int?
↓
buang nil
↓
[Int]
```

Contoh aplikasi nyata.

```
struct User {
    let name: String
    let phone: String?
}

let users = [
    User(
        name: "Ahmad",
        phone: "08111"
    ),
    User(
        name: "Rina",
        phone: nil
    ),
    User(
        name: "Dede",
        phone: "08222"
    )
]
```

Kita ingin mengambil hanya nomor telepon yang benar-benar tersedia.

Kalau:

```
let phones = users.map { user in
    user.phone
}
```

hasil bertipe:

```
[String?]
```

Secara konsep:

```
["08111", nil, "08222"]
```

Tetapi:

```
let phones = users.compactMap { user in
    user.phone
}
```

hasil:

```
["08111", "08222"]
```

tipe:

```
[String]
```

Jadi ini sangat berguna ketika API mempunyai Optional.

Sekarang kita bandingkan tiga method utama hari ini:

```
map
→ ubah semua item

filter
→ pilih item

compactMap
→ ubah item + buang hasil nil
```

Contoh:

```
let students = [...]
```

`map`:

```
students.map { student in
    student.name
}
```

```
[Student] → [String]
```

`filter`:

```
students.filter { student in
    student.score >= 75
}
```

```
[Student] → [Student]
```

`compactMap`:

```
students.compactMap { student in
    student.phone
}
```

jika `phone` adalah `String?`:

```
[Student] → [String]
```

dan semua `nil` dibuang.
