## Evaluasi Hari 6 Bagian 1

Nomor 5

Anda menjawab bahwa `operation` menerima `a` dan `b` bertipe `Int`.

Hampir benar. Tetapi perhatikan:

```
func calculate(
    a: Int,
    b: Int,
    operation: (Int, Int) -> Int
) -> Int {
    return operation(a, b)
}
```

Di sini ada tiga parameter:

|Parameter|Tipe|
|---|---|
|`a`|`Int`|
|`b`|`Int`|
|`operation`|`(Int, Int) -> Int`|

Jadi `operation` menerima sebuah closure, bukan langsung dua angka.

Closure itulah yang nantinya menerima `a` dan `b`.

Nomor 7

Anda menjawab `String`, padahal saya menanyakan tipe closure:

```
{ (name: String) -> String in
    return "Halo \(name)"
}
```

Tipe lengkapnya:

```
(String) -> String
```

Ingat perbedaannya:

- `String` adalah tipe hasil.
    
- `(String) -> String` adalah tipe closure yang menerima String dan menghasilkan String.
