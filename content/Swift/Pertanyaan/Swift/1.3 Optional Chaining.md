Ada satu koreksi penting pada nomor 4. Kode:
```
customer.address!.city
```
tidak crash bukan karena `city` terisi, tetapi karena `address` pada data tersebut tidak `nil`.

`city` sendiri bertipe:
```
String
```

jadi setelah `address` berhasil didapat, `city` memang wajib ada.

customer.address!
