Tanggapan:
Jawaban Anda sangat baik. Secara konsep, 10 dari 10 benar.
Ada satu koreksi kecil tetapi penting pada nomor 9.

`String` tidak berarti harus berisi teks yang terlihat. Ini masih valid:
```
let name: String = ""
```
Karena `""` tetap sebuah String, hanya panjangnya nol.

Perbedaannya lebih tepat:
```
String
→ selalu mempunyai nilai String
→ nil tidak diperbolehkan

String?
→ bisa mempunyai String
→ bisa juga nil
```

Contohnya:
```
let a: String = ""
let b: String? = nil
```
`a` mempunyai nilai, yaitu String kosong.
`b` tidak mempunyai nilai sama sekali.

Ini perbedaan yang nanti penting saat berhadapan dengan backend.
