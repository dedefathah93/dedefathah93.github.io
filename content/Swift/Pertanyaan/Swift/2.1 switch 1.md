Sekarang latihan.

```
enum LoginState {
    case idle
    case loading
    case success(String)
    case failure(String)
}
```

Jawab:

1. Apa arti:

```
case success(String)
```

2. Apa nilai lengkap dari:

```
let state = LoginState.success("Dede")
```

3. String `"Dede"` disebut apa dalam konteks enum ini?
    
4. Pada:
    

```
case .success(let username):
```

apa isi `username` jika state-nya `.success("Dede")`?

5. Apa hasil konsep dari:

```
let state = LoginState.failure(
    "Password salah"
)
```

6. Jika switch:

```
case .failure(let message):
    print(message)
```

apa yang dicetak?

7. Kenapa `LoginState` seperti ini lebih aman dibanding tiga variable terpisah:

```
var isLoading: Bool
var username: String?
var errorMessage: String?
```

8. Apakah `.success("Dede")` dan `.success("Rina")` adalah case yang sama atau berbeda? Jelaskan.
    
9. Apa tipe dari `username` pada:
    

```
case .success(let username)
```

10. Menurut Anda, untuk aplikasi nyata, kapan associated value berguna?

Jawaban:
1. success adalah sebuah case yang membawa satu nilai tambahan, dan nilai tersebut harus bertipe String.
2. .success("Dede")
3. Dalam konteks enum ini, "Dede" disebut associated value
4. "Dede"
5. case = .failure  
    associated value = "Password salah"  
    tipe associated value = String
6. Password salah
7. Masalahnya adalah kombinasi nilai yang tidak masuk akal bisa terjadi.
8. sama
9. String
10. Network/API, Login, Form

Tanggapan
Jawaban Anda sangat baik. **1–7, 9, dan 10 benar.** Nomor 8 perlu sedikit dipertajam karena ini penting untuk memahami associated value.

Untuk:

```
.success("Dede")
.success("Rina")
```

keduanya menggunakan **case yang sama**, yaitu:

```
.success
```

tetapi membawa **associated value yang berbeda**:

```
.success("Dede")
          ↑
        "Dede"

.success("Rina")
          ↑
        "Rina"
```

Jadi kalau pertanyaannya:

> Apakah case-nya sama?

Jawabannya **ya**.

Tetapi kalau pertanyaannya:

> Apakah keseluruhan nilainya identik?

Tidak, karena payload yang dibawanya berbeda.

Mental modelnya:

```
case
↓
.success

associated value
↓
"Dede"
```

Ini mirip kotak dengan jenis yang sama tetapi isi berbeda.

```
success box
└── "Dede"

success box
└── "Rina"
```

Jawaban nomor 10 juga tepat. Associated value memang sangat berguna untuk **network/API, login, form**, dan terutama state aplikasi.

Contoh network:

```
enum LoadState {
    case loading
    case success([Student])
    case failure(String)
}
```

`success` membawa data hasil API:

```
.success(students)
```

sedangkan `failure` membawa informasi error:

```
.failure("Server tidak dapat dihubungi")
```

Ini jauh lebih ekspresif daripada hanya:

```
case success
case failure
```
