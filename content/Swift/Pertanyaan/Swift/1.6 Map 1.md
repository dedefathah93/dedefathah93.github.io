Perhatikan:

```
struct Product {
    let name: String
    let price: Int
}

let products = [
    Product(name: "Keyboard", price: 500_000),
    Product(name: "Mouse", price: 200_000),
    Product(name: "Monitor", price: 2_000_000)
]
```

Jawab:

1. Apa tipe `products`?
2. Apa hasil:

```
products.map { product in
    product.name
}
```

3. Apa tipe hasil nomor 2?
4. Apa hasil:

```
products.map { product in
    product.price
}
```

5. Apa tipe hasil nomor 4?
6. Apa hasil:

```
products.map { product in
    product.price * 2
}
```

7. Apakah `products` berubah setelah `map` dijalankan?
8. Dengan bahasa Anda sendiri, apa fungsi `map`?
9. Kalau kita punya:

```
let labels = products.map { product in
    "\(product.name) - \(product.price)"
}
```

apa isi `labels`?  
10. Menurut Anda kapan lebih enak memakai `map` dibanding `for` manual?

Jawaban:
1. Type dari products adalah Product
2. [“Keyboard”, “Mouse”, “Monitor”]
3. String
4. [500000, 200000, 2000000]
5. Int
6. [1000000, 400000, 4000000]
7. Tidak
8. Ambil setiap data dari array, ubah menjadi data yang baru, lalu hasilkan array baru
9. Labels mempunyai array baru yaitu product
10. Ketika data sudah sangat banyak dan besar

Tanggapan:
Jawaban Anda sudah menangkap inti `map`, terutama nomor 7 dan 8. Ada beberapa koreksi penting sebelum kita lanjut ke `filter`.

Nomor 1, tipe `products` bukan hanya `Product`, tetapi:

```
[Product]
```

Artinya:

```
Array berisi Product
```

Nomor 3 juga sama. Hasil:

```
products.map { product in
    product.name
}
```

adalah:

```
[String]
```

bukan hanya `String`.

Karena hasilnya:

```
["Keyboard", "Mouse", "Monitor"]
```

Begitu juga nomor 5. Hasil:

```
products.map { product in
    product.price
}
```

bertipe:

```
[Int]
```

bukan hanya `Int`.

Ini penting sekali. Bedakan:

```
String
→ satu String

[String]
→ Array berisi String

Int
→ satu Int

[Int]
→ Array berisi Int
```

Nomor 9 belum lengkap. Kode:

```
let labels = products.map { product in
    "\(product.name) - \(product.price)"
}
```

menghasilkan:

```
[
    "Keyboard - 500000",
    "Mouse - 200000",
    "Monitor - 2000000"
]
```

Jadi `labels` bertipe:

```
[String]
```

Nomor 10 perlu kita luruskan sedikit.

`map` bukan lebih cocok hanya karena datanya banyak.

Kalau 3 item maupun 3.000 item, pertanyaannya tetap:

> Apa tujuan saya?

Gunakan `map` ketika tujuan utamanya:

```
ubah setiap item
↓
hasilkan Array baru
```

Contoh:

```
[Product]
↓
ambil name
↓
[String]
```

Sedangkan `for` lebih fleksibel ketika Anda ingin melakukan aksi yang tidak sekadar transformasi.

Contoh:

```
for product in products {
    print(product.name)

    if product.price > 1_000_000 {
        sendAnalytics()
    }
}
```

Jadi mental modelnya:

```
map
→ TRANSFORMASI

for
→ ITERASI umum
```

Dengan ini `map` saya anggap cukup dipahami.
