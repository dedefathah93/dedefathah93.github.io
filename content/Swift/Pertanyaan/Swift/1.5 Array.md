Perhatikan:

```
struct Transaction {
    let title: String
    let amount: Int
}

let transactions = [
    Transaction(
        title: "Makan",
        amount: 50_000
    ),
    Transaction(
        title: "Bensin",
        amount: 100_000
    ),
    Transaction(
        title: "Internet",
        amount: 150_000
    ),
    Transaction(
        title: "Parkir",
        amount: 10_000
    )
]

func calculateTotal(
    transactions: [Transaction]
) -> Int {

    var total = 0

    for transaction in transactions {
        total += transaction.amount
    }

    return total
}
```

Jawab:

1. Apa tipe dari `transactions`?
    
2. Ada berapa item di dalam `transactions`?
    
3. Apa hasil:
    

```
transactions.count
```

4. Apa hasil:

```
transactions[1].title
```

5. Apa hasil:

```
transactions[2].amount
```

6. Apa tugas variable:

```
var total = 0
```

7. Pada loop pertama, nilai `transaction.amount` berapa?
    
8. Setelah loop kedua selesai, nilai `total` berapa?
    
9. Berapa hasil akhir `calculateTotal(transactions: transactions)`?
    
10. Kenapa `total` harus dibuat sebelum `for`, bukan di dalam `for`?
    
11. Apa yang terjadi jika kita mencoba:
    

```
transactions[10]
```

12. Dengan bahasa Anda sendiri, jelaskan:

```
for transaction in transactions
```

Kalau bagian ini sudah kuat, kita lanjut Hari 4 Bagian 2 ke `map`, dan di sana Anda akan melihat bagaimana Swift bisa mengubah:


menjadi:

```

```

Tanggapan:
Bagian ini sudah cukup bagus, tetapi ada tiga koreksi penting sebelum kita masuk `map`.

Nomor 1, jawaban lebih tepat bukan hanya `Array`, tetapi:

```
[Transaction]
```

Artinya:

```
Array yang berisi Transaction
```

Ini penting karena Swift sangat peduli dengan tipe isi Array.

Nomor 3 salah sedikit. Karena datanya:

```
Makan
Bensin
Internet
Parkir
```

jumlahnya 4, jadi:

```
transactions.count
```

hasilnya:

```
4
```

Nomor 9 juga perlu dikoreksi. Totalnya:

```
50.000
+ 100.000
+ 150.000
+ 10.000
=
310.000
```

Jadi hasil akhirnya:

```
310_000
```

Nomor 12 arah Anda benar. Lebih lengkapnya:

```
for transaction in transactions
```

artinya:

> Ambil setiap satu `Transaction` dari Array `transactions`, lalu jalankan blok kode untuk setiap item tersebut.

Secara mental:

```
transactions
↓
Transaction pertama
↓
transaction

Transaction kedua
↓
transaction

Transaction ketiga
↓
transaction

Transaction keempat
↓
transaction
```

Dengan itu, Bagian 1 saya anggap cukup.
