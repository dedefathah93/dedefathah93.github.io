Sebenarnya Anda sudah menggunakan closure sejak Hari 4.

Contoh:
```
students.map { student in
    student.name
}
```

Bagian ini:
```
{ student in
    student.name
}
```
adalah closure.

Closure pada dasarnya adalah:
> function yang tidak harus punya nama.

Bandingkan function biasa:
```
func double(number: Int) -> Int {
    return number * 2
}
```

dengan closure:
```
let double = { (number: Int) -> Int in
    return number * 2
}
```

Keduanya bisa digunakan:
```
let result = double(5)
```

hasil:
```
10
```

Perbedaannya adalah yang pertama dideklarasikan sebagai function:
```
func double(...)
```

sedangkan yang kedua adalah closure yang disimpan ke variable:
```
let double = { ... }
```

## Function bisa dianggap sebagai value

Ini konsep yang mungkin terasa aneh pada awalnya.
Kita biasa menyimpan:
```
let name = "Dede"
```

atau:
```
let score = 90
```

Tetapi Swift juga bisa menyimpan function/closure:
```
let operation = { (a: Int, b: Int) -> Int in
    return a + b
}
```

Sekarang:
```
operation
```

adalah sesuatu yang bisa dipanggil:
```
let result = operation(10, 20)
```

hasil:
```
30
```

Jadi secara mental:
```
String
bisa disimpan dalam variable

Int
bisa disimpan dalam variable

Closure
juga bisa disimpan dalam variable
```

---

# Tipe closure

Perhatikan:
```
let operation = { (a: Int, b: Int) -> Int in
    return a + b
}
```

Tipe closure tersebut adalah:
```
(Int, Int) -> Int
```

Artinya:
```
menerima Int
menerima Int
↓
menghasilkan Int
```

Ini sangat mirip dengan signature function:
```
func add(
    a: Int,
    b: Int
) -> Int
```

Konsep tipenya sama:
```
(Int, Int) -> Int
```

---

# Closure tanpa parameter

Misalnya:
```
let sayHello = {
    print("Halo")
}
```

Dipanggil:
```
sayHello()
```

Tipe closure:
```
() -> Void
```

Artinya:
```
tidak menerima parameter
↓
tidak mengembalikan nilai
```

`Void` secara sederhana berarti tidak ada nilai hasil yang penting.

---

# Closure sebagai parameter function

Sekarang bagian yang sangat penting.
Kita bisa membuat function yang menerima closure.

Contoh:
```
func performOperation(
    a: Int,
    b: Int,
    operation: (Int, Int) -> Int
) -> Int {

    return operation(a, b)
}
```

Perhatikan parameter:
```
operation: (Int, Int) -> Int
```

Artinya function membutuhkan sebuah closure yang:
```
menerima dua Int
menghasilkan Int
```

Kita bisa panggil:
```
let result = performOperation(
    a: 10,
    b: 5,
    operation: { a, b in
        return a + b
    }
)
```

hasil:
```
15
```

Atau:
```
let result = performOperation(
    a: 10,
    b: 5,
    operation: { a, b in
        return a * b
    }
)
```

hasil:
```
50
```

Function yang sama:
```
performOperation
```

bisa menerima behavior yang berbeda.
Ini salah satu alasan closure sangat kuat.

# Hubungan dengan `map`

Sekarang Anda bisa mulai memahami kenapa:

```
students.map { student in
    student.name
}
```
bekerja.

Secara konsep, `map` menerima closure.

Kurang lebih mental model-nya:
```
map(
    transform: (Student) -> String
)
```

Closure kita:
```
{ student in
    student.name
}
```

menerima:
```
Student
```

dan menghasilkan:
```
String
```

Jadi cocok dengan:
```
(Student) -> String
```

Maka:
```
[Student]
```

berubah menjadi:
```
[String]
```

Sekarang `map` tidak lagi terasa seperti syntax ajaib.

# Closure shorthand `$0`

Anda sebelumnya sudah melihat:
```
students.map {
    $0.name
}
```
`$0` berarti parameter pertama closure.

Jadi:
```
students.map { student in
    student.name
}
```

bisa dipersingkat menjadi:
```
students.map {
    $0.name
}
```

Untuk sekarang, jangan buru-buru memakai `$0` di semua tempat.

Versi:
```
{ student in ... }
```

lebih baik selama Anda masih melatih membaca aliran data.

## Hari 6 Bagian 2: Trailing Closure

Di Swift, closure sangat sering menjadi parameter terakhir sebuah function.

Contoh yang telah kita pelajari:

```
func calculate(
    a: Int,
    b: Int,
    operation: (Int, Int) -> Int
) -> Int {
    return operation(a, b)
}
```

Pemanggilan biasa:

```
let result = calculate(
    a: 10,
    b: 5,
    operation: { a, b in
        return a + b
    }
)
```

Swift mengizinkan closure terakhir dipindahkan ke luar tanda kurung.

```
let result = calculate(a: 10, b: 5) { a, b in
    return a + b
}
```

Hasilnya tetap:

```
15
```

Inilah yang disebut trailing closure syntax.

Bentuk biasa

```
calculate(
    a: 10,
    b: 5,
    operation: { a, b in
        return a + b
    }
)
```

Trailing closure

Bentuk lebih ringkas

```
calculate(a: 10, b: 5) { a, b in
    return a + b
}
```

Ini bukan dua mekanisme berbeda. Keduanya memanggil function yang sama.

### Mengapa ini penting untuk SwiftUI?

Karena hampir setiap hari nanti Anda akan melihat:

```
Button("Simpan") {
    save()
}
```

Sekarang kita bedah.

`Button` menerima teks judul dan sebuah closure yang dijalankan ketika tombol ditekan.

Secara konsep:

```
Button
├── title: "Simpan"
└── action: closure
              ↓
             save()
```

Closure action ini tidak menerima parameter dan tidak mengembalikan nilai, sehingga tipenya:

```
() -> Void
```

Ketika Anda membaca:

```
Button("Simpan") {
    save()
}
```

Anda seharusnya mulai berpikir:

> Function atau initializer Button menerima sebuah closure. Closure ini akan dijalankan sebagai respons terhadap tindakan user.

Ini berbeda dari:

```
Button("Simpan") {
    print("Simpan")
}
```

yang langsung menjalankan `print` saat closure dipanggil oleh tombol, bukan saat kode View pertama kali dibentuk.

## Hari 6 Bagian 3: Closure menangkap variable dari luar (Capture)

Sekarang ada kemampuan closure yang belum kita bahas.

Perhatikan:

```
let tax = 10

let calculateTax = { (price: Int) -> Int in
    return price * tax / 100
}
```

Di dalam closure ada:

```
tax
```

Padahal `tax` tidak diberikan sebagai parameter.

Parameter closure hanya:

```
price: Int
```

Bagaimana closure bisa membaca `tax`?

Karena closure dapat menangkap (capture) nilai atau variable dari lingkungan tempat closure dibuat.

Alur capture

```
let tax = 10
```

Nilai dari scope luar

```
let calculateTax = { (price: Int) -> Int in
    price * tax / 100
}
```

Closure menggunakan `price` sebagai input dan menangkap `tax` dari luar

```
calculateTax(200_000)
```

# 20.000

Nilai hasil

Sekarang contoh dengan `var`:

```
var counter = 0

let increment = {
    counter += 1
}

increment()
increment()
increment()

print(counter)
```

Hasil:

```
3
```

Kenapa?

Karena closure menggunakan variable `counter` dari scope luar. Setiap pemanggilan meningkatkan nilai variable tersebut.

Perhatikan bahwa closure tidak memiliki parameter `counter`.

### Hubungan dengan SwiftUI `@State`

Sekarang contoh SwiftUI yang lebih realistis:

```
import SwiftUI

struct CounterView: View {
    @State private var count = 0

    var body: some View {
        VStack {
            Text("Count: \(count)")

            Button("Tambah") {
                count += 1
            }
        }
    }
}
```

Di bagian:

```
Button("Tambah") {
    count += 1
}
```

closure mengakses property `count` dari `CounterView`.

Saat Button ditekan:

1. Closure dijalankan.
    
2. `count` bertambah.
    
3. SwiftUI mendeteksi perubahan state.
    
4. Tampilan diperbarui sesuai nilai baru.
    

Ini salah satu hubungan langsung antara materi closure sekarang dan SwiftUI pada bulan berikutnya.

Catatan engineering: capture pada closure juga memiliki aturan ownership dan lifetime yang akan kita pelajari nanti, termasuk `weak self` dan retain cycle pada class. Untuk sekarang, cukup kuasai bahwa closure dapat menggunakan nilai dari scope sekitarnya.
