Perhatikan requirement:

> User mengisi username dan password. Jika salah satu kosong, tampilkan error. Jika keduanya valid, buat teks ringkasan login.

Kita bisa memecahnya:

```
func validateLogin(
    username: String,
    password: String
) -> String? {

    guard !username.isEmpty else {
        return "Username wajib diisi"
    }

    guard !password.isEmpty else {
        return "Password wajib diisi"
    }

    return nil
}
```

Kemudian:

```
func makeLoginSummary(
    username: String
) -> String {
    return "Login sebagai \(username)"
}
```

Lalu:

```
func processLogin(
    username: String,
    password: String
) -> String {

    if let error = validateLogin(
        username: username,
        password: password
    ) {
        return error
    }

    return makeLoginSummary(
        username: username
    )
}
```

Perhatikan struktur berpikirnya:

```
processLogin
    │
    ├── validateLogin
    │
    └── makeLoginSummary
```

Satu masalah besar dipecah menjadi function-function kecil.

Ini cara Anda nanti membaca project besar.

Jangan melihat:

```
5000 baris kode
```

sebagai satu benda.
