Perhatikan:

```
func greet(name: String) {
    print("Halo \(name)")
}
```

Pemanggilannya:

```
greet(name: "Dede")
```

`name:` di luar function disebut argument label.

Sekarang contoh:

```
func sendMessage(
    to recipient: String,
    message: String
) {
    print("Kirim ke \(recipient): \(message)")
}
```

Dipanggil:

```
sendMessage(
    to: "Ahmad",
    message: "Halo"
)
```

Di dalam function, nama variablenya:

```
recipient
message
```

Tetapi dari luar:

```
to:
message:
```

Kenapa berguna?

Karena pemanggilan menjadi lebih natural:

```
sendMessage(to: "Ahmad", message: "Halo")
```

daripada:

```
sendMessage(recipient: "Ahmad", message: "Halo")
```

Swift cukup peduli pada keterbacaan API.

Sekarang ada underscore:

```
func square(_ number: Int) -> Int {
    return number * number
}
```

Dipanggil:

```
let result = square(5)
```

Bukan:

```
square(number: 5)
```

Karena `_` berarti tidak ada argument label dari luar.

Sekarang default parameter.

```
func greet(
    name: String,
    prefix: String = "Halo"
) {
    print("\(prefix) \(name)")
}
```

Bisa dipanggil:

```
greet(name: "Dede")
```

hasil:

```
Halo Dede
```

Atau:

```
greet(
    name: "Dede",
    prefix: "Wilujeng"
)
```

hasil:

```
Wilujeng Dede
```

Karena `prefix` sudah punya default.

Sekarang kita gabungkan `guard`.

```
func calculateDiscount(
    price: Int,
    discount: Int
) -> Int {

    guard price > 0 else {
        return 0
    }

    guard discount >= 0 else {
        return price
    }

    let discountAmount = price * discount / 100
    return price - discountAmount
}
```

Artinya:

```
price harus > 0
↓
kalau tidak
return 0
↓
function berhenti
```

Lalu:

```
discount harus >= 0
↓
kalau tidak
return price
```

`guard` di sini bukan untuk Optional, tetapi untuk validasi syarat.

Ini penting. `guard` tidak hanya digunakan bersama `guard let`.

Sekarang perhatikan function ini:

```
func calculatePurchase(
    price: Int,
    quantity: Int,
    discount: Int = 0
) -> Int {

    guard price > 0 else {
        return 0
    }

    guard quantity > 0 else {
        return 0
    }

    let subtotal = price * quantity
    let discountAmount = subtotal * discount / 100

    return subtotal - discountAmount
}
```

Pemanggilan pertama:

```
let totalA = calculatePurchase(
    price: 100_000,
    quantity: 3
)
```

Pemanggilan kedua:

```
let totalB = calculatePurchase(
    price: 100_000,
    quantity: 3,
    discount: 10
)
```
