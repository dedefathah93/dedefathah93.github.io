Sekarang kita naik sedikit.

Perhatikan:
```
struct BankAccount {
    let owner: String
    var balance: Int
}

var account = BankAccount(
    owner: "Dede",
    balance: 1_000_000
)

account.balance = 1_500_000
```

`mutation` secara sederhana berarti perubahan terhadap data.

Di sini:
```
account.balance = 1_500_000
```
adalah mutation.

Sebelumnya:
```
balance = 1.000.000
```

sesudah:
```
balance = 1.500.000
```

Hal ini kelihatannya sederhana, tetapi nanti sangat berhubungan dengan SwiftUI.

Misalnya:
```
@State var count = 0
```

lalu:
```
count += 1
```

itu juga mutation.
Dan SwiftUI mengamati perubahan state tersebut lalu memperbarui tampilan.

## Sekarang konsep yang sangat khas Swift: value semantics

Perhatikan kode berikut:
```
struct Product {
    var name: String
    var price: Int
}

var productA = Product(
    name: "Keyboard",
    price: 500_000
)

var productB = productA

productB.price = 700_000

print(productA.price)
print(productB.price)
```

Coba jangan buru-buru menjawab.

Urutannya:
```
productA
Keyboard
500.000
```

kemudian:
```
var productB = productA
```

Karena `Product` adalah `struct`, secara konsep `productB` mendapatkan nilainya sendiri.

Kemudian:
```
productB.price = 700_000
```

Perubahan tersebut hanya mengenai `productB`.

Jadi:
```
productA → 500.000
productB → 700.000
```

Output:
```
500000
700000
```

Ini disebut value semantics.

Mental model awalnya:

```
STRUCT

productA
[Keyboard, 500000]

       COPY

productB
[Keyboard, 500000]

productB.price = 700000

productA
[Keyboard, 500000]

productB
[Keyboard, 700000]
```

Mereka menjadi dua nilai independen.

Nanti ketika kita masuk `class`, perilakunya bisa berbeda.
