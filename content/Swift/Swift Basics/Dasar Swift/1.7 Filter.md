Misalnya:

```
struct Student {
    let name: String
    let score: Int
}

let students = [
    Student(name: "Ahmad", score: 80),
    Student(name: "Rina", score: 90),
    Student(name: "Dede", score: 60),
    Student(name: "Budi", score: 70)
]
```

Kita hanya ingin siswa yang lulus.

Dengan loop manual:

```
var passedStudents: [Student] = []

for student in students {
    if student.score >= 75 {
        passedStudents.append(student)
    }
}
```

Hasil:

```
Ahmad
Rina
```

Swift menyediakan:

```
let passedStudents = students.filter { student in
    student.score >= 75
}
```

`filter` artinya:

> Periksa setiap item. Kalau kondisi `true`, pertahankan. Kalau `false`, buang dari hasil.

Alurnya:

```
Ahmad 80
80 >= 75
true
→ masuk

Rina 90
90 >= 75
true
→ masuk

Dede 60
60 >= 75
false
→ tidak masuk

Budi 70
70 >= 75
false
→ tidak masuk
```

Hasil:

```
[
    Student(name: "Ahmad", score: 80),
    Student(name: "Rina", score: 90)
]
```

Perhatikan bedanya dengan `map`.

`map`:

```
[Student]
↓
ubah
↓
[String]
```

`filter`:

```
[Student]
↓
pilih
↓
[Student]
```

Biasanya tipe elemennya tetap sama.

Contoh transaksi:

```
struct Transaction {
    let title: String
    let amount: Int
}

let transactions = [
    Transaction(title: "Makan", amount: 50_000),
    Transaction(title: "Bensin", amount: 100_000),
    Transaction(title: "Internet", amount: 150_000),
    Transaction(title: "Parkir", amount: 10_000)
]
```

Kita ingin transaksi di atas atau sama dengan Rp100.000:

```
let expensiveTransactions = transactions.filter { transaction in
    transaction.amount >= 100_000
}
```

Hasil:

```
Bensin
Internet
```

Karena:

```
Makan     50.000   → false
Bensin   100.000   → true
Internet 150.000   → true
Parkir    10.000   → false
```

Kita juga bisa:

```
let cheapTransactions = transactions.filter { transaction in
    transaction.amount < 100_000
}
```

Hasil:

```
Makan
Parkir
```

Sekarang shorthand lagi:

```
let expensiveTransactions = transactions.filter {
    $0.amount >= 100_000
}
```

Sama dengan:

```
let expensiveTransactions = transactions.filter { transaction in
    transaction.amount >= 100_000
}
```

Untuk sekarang tetap gunakan versi panjang jika lebih mudah dibaca.

Sekarang kita bisa menggabungkan `filter` dan `map`.

Contoh:

```
let names = students
    .filter { student in
        student.score >= 75
    }
    .map { student in
        student.name
    }
```

Baca dari atas:

```
students
↓
filter siswa lulus
↓
[Ahmad, Rina sebagai Student]
↓
map ambil name
↓
["Ahmad", "Rina"]
```

Ini disebut chaining.

Perhatikan bahwa urutan operasi penting.

```
students
    .filter(...)
    .map(...)
```

berarti:

```
pilih dulu
baru ubah
```

Contoh nyata presensi:

```
struct Student {
    let name: String
    let present: Bool
}
```

Kemudian:

```
let absentNames = students
    .filter { student in
        !student.present
    }
    .map { student in
        student.name
    }
```

`!` pada Bool berarti kebalikan.

Kalau:

```
present = true
```

maka:

```
!present = false
```

Kalau:

```
present = false
```

maka:

```
!present = true
```

Jadi:

```
!student.present
```

berarti:

> siswa yang tidak hadir.
