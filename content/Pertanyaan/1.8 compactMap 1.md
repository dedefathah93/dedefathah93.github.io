Sekarang latihan bagian terakhir Hari 4.

Perhatikan:

```
struct Student {
    let name: String
    let score: Int
    let email: String?
}

let students = [
    Student(
        name: "Ahmad",
        score: 80,
        email: "ahmad@mail.com"
    ),
    Student(
        name: "Rina",
        score: 60,
        email: nil
    ),
    Student(
        name: "Dede",
        score: 90,
        email: "dede@mail.com"
    ),
    Student(
        name: "Budi",
        score: 70,
        email: nil
    )
]
```

Jawab:

1. Apa tipe `students`?
    
2. Apa hasil:
    

```
students.map { student in
    student.name
}
```

3. Apa tipe hasil nomor 2?
    
4. Apa hasil:
    

```
students.filter { student in
    student.score >= 75
}
```

Cukup sebut nama siswanya.

5. Apa tipe hasil nomor 4?
    
6. Apa hasil:
    

```
students.map { student in
    student.email
}
```

7. Apa tipe hasil nomor 6?
    
8. Apa hasil:
    

```
students.compactMap { student in

```

9. Apa tipe hasil nomor 8?

Tanggapan:
Hari 4 sudah hampir sepenuhnya dikuasai. Dari 12 soal, ada dua kesalahan tipe data yang penting untuk diperbaiki. Selebihnya benar.

Nomor 5:

```
students.filter { student in
    student.score >= 75
}
```

Anda menjawab:

```
[String]
```

Yang benar:

```
[Student]
```

Karena `filter` tidak mengubah `Student` menjadi `String`. Ia hanya memilih `Student` mana yang dipertahankan.

```
[Student]
↓ filter
[Student]
```

Sedangkan kalau setelah itu kita gunakan:

```
.map { student in
    student.name
}
```

barulah:

```
[Student]
↓ map
[String]
```

Nomor 7 juga perlu diperbaiki. Kode:

```
students.map { student in
    student.email
}
```

menghasilkan tipe:

```
[String?]
```

bukan:

```
[String]
```

Karena `email` sendiri bertipe:

```
String?
```

Maka hasilnya secara konsep:

```
[
    "ahmad@mail.com",
    nil,
    "dede@mail.com",
    nil
]
```

Sedangkan:

```
students.compactMap { student in
    student.email
}
```

barulah menghasilkan:

```
[String]
```

karena `nil` dibuang.

Satu catatan penulisan Swift:

```
nil
```

bukan:

```
nill
```

Jawaban nomor 10 sudah menangkap konsepnya. Saya pertajam sedikit:

```
map
→ transformasikan setiap item

filter
→ pilih item berdasarkan kondisi true/false

compactMap
→ transformasikan setiap item
→ buang hasil yang nil
```

Nomor 11 benar. Hasil lengkapnya:

```
["Ahmad", "Dede"]
```

Nomor 12 juga benar:

```
["ahmad@mail.com", "dede@mail.com"]
```
