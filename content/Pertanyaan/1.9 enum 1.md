Jawaban Anda sudah menangkap inti `enum`, tetapi nomor 2, 5, dan 10 perlu diluruskan. Ketiganya justru menyentuh konsep penting.

### Koreksi nomor 2

Kode ini:

```
let order = Order(
    id: 100,
    status: "diproses"
)
```

**tidak valid**.

Karena property:

```
let status: OrderStatus
```

meminta nilai bertipe:

```
OrderStatus
```

bukan `String`.

Yang benar:

```
let order = Order(
    id: 100,
    status: .processing
)
```

Memang `.processing` memiliki raw value:

```
"diproses"
```

tetapi keduanya tetap tipe yang berbeda:

```
.processing
→ OrderStatus

"diproses"
→ String
```

Kalau ingin mengubah String menjadi enum, barulah:

```
let status = OrderStatus(
    rawValue: "diproses"
)
```

### Koreksi nomor 5

Anda menjawab:

```
OrderStatus
```

Padahal:

```
OrderStatus(rawValue: "dikirim")
```

menghasilkan:

```
OrderStatus?
```

Perhatikan tanda:

```
?
```

Kenapa Optional?

Karena operasi tersebut bisa gagal.

```
OrderStatus(rawValue: "dikirim")
// .shipped
```

tetapi:

```
OrderStatus(rawValue: "hilang")
// nil
```

Swift tidak bisa menjamin String yang diberikan selalu cocok dengan salah satu case.

Jadi:

```
rawValue String
↓
coba ubah menjadi enum
↓
OrderStatus?
```

### Koreksi nomor 10, ini yang paling penting

Backend mengirim:

```
{
    "id": 100,
    "status": "dikemas"
}
```

sedangkan enum hanya:

```
enum OrderStatus: String, Codable {
    case waiting = "menunggu"
    case processing = "diproses"
    case shipped = "dikirim"
    case completed = "selesai"
    case cancelled = "dibatalkan"
}
```

Anda menjawab:

```
OrderStatus?
```

Itu **bukan** yang terjadi pada `JSONDecoder`.

Karena modelnya:

```
struct Order: Codable {
    let id: Int
    let status: OrderStatus
}
```

`status` wajib berupa `OrderStatus`.

Ketika decoder menemukan:

```
"status": "dikemas"
```

tetapi enum tidak mengenalnya:

```
JSONDecoder
↓
coba decode OrderStatus
↓
"dikemas" tidak ditemukan
↓
DecodingError
↓
seluruh Order gagal di-decode
```

Ini berbeda dengan:

```
OrderStatus(rawValue: "dikemas")
```

yang menghasilkan:

```
nil
```

Jadi bedakan:

```
OrderStatus(rawValue: ...)
→ gagal = nil

JSONDecoder.decode(...)
→ gagal = throws DecodingError
```

Ini konsep yang sangat penting.
