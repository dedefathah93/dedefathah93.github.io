Perhatikan:

```
let multiply = { (a: Int, b: Int) -> Int in
    return a * b
}
```

dan:

```
func calculate(
    a: Int,
    b: Int,
    operation: (Int, Int) -> Int
) -> Int {

    return operation(a, b)
}
```

Jawab:

1. Apa itu `multiply`?
2. Apa tipe `multiply`?
3. Apa hasil:

```
multiply(4, 5)
```

4. Apa arti:

```
(Int, Int) -> Int
```

5. Pada function `calculate`, parameter `operation` menerima apa?
6. Apa hasil:

```
calculate(
    a: 10,
    b: 3,
    operation: { a, b in
        return a - b
    }
)
```

7. Apa tipe closure ini?

```
{ (name: String) -> String in
    return "Halo \(name)"
}
```

8. Apa hasil jika closure nomor 7 dipanggil dengan `"Dede"`?
9. Pada:

```
students.map { student in
    student.name
}
```

closure tersebut menerima tipe apa?  
10. Closure tersebut menghasilkan tipe apa?  
11. Jadi secara konsep tipe closure pada `map` itu apa?
