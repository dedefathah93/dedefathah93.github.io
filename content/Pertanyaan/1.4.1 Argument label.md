Sekarang perhatikan function ini:

```
func calculatePurchase(
    price: Int,
    quantity: Int,
    discount: Int = 0
) -> Int {

    guard price > 0 else {
        return 0
    }

    guard quantity > 0 else {
        return 0
    }

    let subtotal = price * quantity
    let discountAmount = subtotal * discount / 100

    return subtotal - discountAmount
}
```

Pemanggilan pertama:

```
let totalA = calculatePurchase(
    price: 100_000,
    quantity: 3
)
```

Pemanggilan kedua:

```
let totalB = calculatePurchase(
    price: 100_000,
    quantity: 3,
    discount: 10
)
```

Sekarang jawab:

1. Kenapa `discount` tidak wajib ditulis pada pemanggilan pertama?
2. Berapa nilai default `discount`?
3. Berapa `subtotal` untuk `totalA`?
4. Berapa `discountAmount` untuk `totalA`?
5. Berapa hasil `totalA`?
6. Berapa `subtotal` untuk `totalB`?
7. Berapa `discountAmount` untuk `totalB`?
8. Berapa hasil `totalB`?
9. Apa yang terjadi kalau `quantity = 0`?
10. Kenapa function langsung berhenti setelah `return 0` di dalam `guard`?

Jawaban:
1. karena discount sudah punya nilai default, jadi kalaupun tidak menulis nanti discount berapa, dia akan menggunakan angka default
2. 0
3. 100000 * 3 = 300000
4. 300000 * 0 / 100 = 0
5. 300000 - 0 = 300000
6. 100000 * 3 = 300000
7. 300000 * 10 / 100 = 30000
8. 300000 - 30000 = 270000
9. dia akan langsung mengembalikan nilai 0, karena quantity meminta lebih dari 0
10. karena tidak ada lagi yang bisa di proses, dan guard menuntut lebih dari 0

Tanggapan:
Benar. Jawaban Anda 10/10 secara konsep.

Koreksi kecil hanya pada nomor 10. Alasan paling tepat bukan karena “tidak ada lagi yang bisa diproses”, tetapi karena `return` memang langsung mengakhiri function.

Contoh:

```
func test(value: Int) -> Int {
    guard value > 0 else {
        return 0
    }

    print("Baris ini hanya dijalankan kalau value > 0")

    return value
}
```

Kalau:

```
test(value: 0)
```

alur program:

```
value > 0 ?
↓
tidak
↓
return 0
↓
FUNCTION SELESAI
```

Baris setelah `return` tidak dijalankan.

Dengan ini, pemahaman Anda tentang parameter, default value, `guard`, dan `return` sudah cukup baik.
