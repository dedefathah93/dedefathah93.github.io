Sekarang latihan.

```
struct Product {
    let name: String
    let price: Int
    let inStock: Bool
}

let products = [
    Product(
        name: "Keyboard",
        price: 500_000,
        inStock: true
    ),
    Product(
        name: "Mouse",
        price: 200_000,
        inStock: false
    ),
    Product(
        name: "Monitor",
        price: 2_000_000,
        inStock: true
    ),
    Product(
        name: "Kabel",
        price: 50_000,
        inStock: true
    )
]
```

Jawab:

1. Apa hasil:

```
products.filter { product in
    product.inStock
}
```

Cukup sebutkan nama produknya.

2. Apa hasil:

```
products.filter { product in
    product.price >= 500_000
}
```

3. Apa hasil:

```
products.filter { product in
    !product.inStock
}
```

4. Apa tipe hasil dari `filter` di atas?
    
5. Apakah Array `products` asli berubah setelah `filter`?
    
6. Dengan bahasa Anda sendiri, apa fungsi `filter`?
    
7. Apa hasil:
    

```
let names = products
    .filter { product in
        product.inStock
    }
    .map { product in
        product.name
    }
```

8. Apa tipe `names`?
    
9. Jelaskan urutan kerja nomor 7 dari `products` sampai hasil akhir.
    
10. Apa perbedaan paling penting antara `map` dan `filter` menurut pemahaman Anda?

Jawaban:
1. Keyboard, Monitor, Kabel sebagai Products
2. Keyboard, Monitor
3. Mouse
4. false
5. Tidak
6. Untuk menghasilkan nilai yang sesuai dengan kriteria filter
7. [“Keyboard”, “Mouse”, “Monitor”, “Kabel”]
8. Array dengan products.name
9. Dia mencari dengan kategori poduct.inStock brrti yang menghasilkan true, kemudian menjadi array baru dengan nama names
10. Map adalah mengahilkan array baru, sedangkan filter lebih mencari sesuai kategori

Tanggapan:
Bagian `filter` sudah cukup dipahami, tetapi ada tiga koreksi penting sebelum kita masuk `compactMap`.

Nomor 1 benar:

```
Keyboard
Monitor
Kabel
```

Karena hanya ketiganya yang mempunyai:

```
inStock == true
```

Nomor 2 benar:

```
Keyboard
Monitor
```

Nomor 3 juga benar:

```
Mouse
```

karena:

```
!product.inStock
```

memilih item dengan `inStock == false`.

Nomor 4 yang perlu diperbaiki. Saya menanyakan tipe hasil `filter`, bukan nilai kondisi.

Kalau sumbernya:

```
products
```

bertipe:

```
[Product]
```

maka:

```
products.filter { ... }
```

juga menghasilkan:

```
[Product]
```

Jadi mental modelnya:

```
[Product]
   ↓
 filter
   ↓
[Product]
```

Filter hanya memilih sebagian item. Ia tidak mengubah `Product` menjadi tipe lain.

Nomor 5 dan 6 benar.

Nomor 7 masih salah sedikit.

Kode:

```
let names = products
    .filter { product in
        product.inStock
    }
    .map { product in
        product.name
    }
```

Pertama:

```
filter
```

menghasilkan:

```
Keyboard
Monitor
Kabel
```

`Mouse` dibuang karena:

```
inStock == false
```

Baru kemudian `map` mengambil `name`.

Hasil akhir:

```
[
    "Keyboard",
    "Monitor",
    "Kabel"
]
```

Nomor 8, tipe `names` adalah:

```
[String]
```

Bukan “Array dengan products.name”.

Ini penting untuk membiasakan membaca tipe Swift secara presisi.

Nomor 9 arahnya benar. Urutannya:

```
[Product]
↓
filter product.inStock == true
↓
[Product]
Keyboard, Monitor, Kabel
↓
map ambil name
↓
[String]
"Keyboard", "Monitor", "Kabel"
```

Nomor 10 juga arahnya benar, tetapi kita buat definisinya lebih tajam:

```
map
→ mengubah setiap item
→ menghasilkan Array baru

filter
→ memilih item berdasarkan kondisi Bool
→ menghasilkan Array baru berisi item yang lolos
```

Contoh:

```
products.map { product in
    product.name
}
```

berarti:

```
Product → String
```

Sedangkan:

```
products.filter { product in
    product.inStock
}
```

berarti:

```
Product → dicek true/false
```

Kalau `true`, Product dipertahankan.

Kalau `false`, Product tidak dimasukkan ke hasil.

Dengan itu, `filter` saya anggap cukup.
