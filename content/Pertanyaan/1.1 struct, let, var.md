Saya ingin memastikan Anda benar-benar memahami `struct`, `let`, `var`, property dan computed property.

Perhatikan:
```
struct Product {
    let name: String
    var price: Int
    var stock: Int

    var available: Bool {
        stock > 0
    }

    var totalValue: Int {
        price * stock
    }
}

var product = Product(
    name: "Keyboard",
    price: 500_000,
    stock: 3
)

product.stock = 2

print(product.name)
print(product.stock)
print(product.available)
print(product.totalValue)
```

Jawab hanya enam pertanyaan berikut:
1. Apa yang didefinisikan oleh `struct Product`?
2. Kenapa `name` memakai `let`, sedangkan `price` dan `stock` menggunakan `var`?
3. Kenapa variable `product` menggunakan `var`?
4. Apakah `available` disimpan sebagai data, atau dihitung? Jelaskan dari data apa.
5. Apakah `totalValue` disimpan sebagai data, atau dihitung? Berapa nilainya pada akhir program?
6. Apa seluruh output empat `print` tersebut?

Tanggapan :
Bagus. Secara konsep Anda sudah mulai menangkap hubungan antara `struct`, property, `let/var`, dan computed property. Ada dua bagian yang perlu kita luruskan sebelum lanjut.

Nilai latihan ini saya beri sekitar 4,5/6. Yang lebih penting, kesalahannya sekarang spesifik dan mudah diperbaiki.

### Koreksi jawaban Anda

1. Jawaban Anda: `name, price, stock`

Belum tepat sepenuhnya.

`struct Product` bukan hanya mendefinisikan ketiga property itu. Ia mendefinisikan satu tipe/model bernama `Product`.

```
struct Product {
    let name: String
    var price: Int
    var stock: Int
}
```

Artinya kita mengatakan:

```
Product
harus mempunyai:

name  → String
price → Int
stock → Int
```

Lalu kita bisa membuat banyak Product:

```
let keyboard = Product(
    name: "Keyboard",
    price: 500_000,
    stock: 3
)

let mouse = Product(
    name: "Mouse",
    price: 200_000,
    stock: 5
)
```

Jadi ingat:

```
struct Product
= definisi / model / tipe

product
= satu data Product yang nyata
```

Ini konsep penting.

2. Jawaban Anda benar.

> name tidak boleh berubah, price dan stock mungkin berubah.

Tepat.

Misalnya nama produknya tetap:

```
let name: String
```

tetapi harga dan stok mungkin berubah:

```
var price: Int
var stock: Int
```

3. Jawaban Anda juga benar secara konsep.

Karena nanti kita melakukan:

```
product.stock = 2
```

maka:

```
var product
```

memang diperlukan.

Ada detail penting:

```
struct Product {
    var stock: Int
}
```

belum cukup untuk membuatnya dapat diubah.

Kalau kita membuat:

```
let product = Product(...)
```

kemudian:

```
product.stock = 2
```

tetap error.

Karena `Product` adalah `struct`.

Jadi untuk sekarang ingat kombinasi ini:

```
property var
+
object var
=
property bisa diubah
```

4. Jawaban Anda arahnya benar.

Anda mengatakan `stock` yang menjadi data.

Lebih tepatnya:

```
var available: Bool {
    stock > 0
}
```

`available` adalah computed property.

Ia tidak menyimpan nilai sendiri.

Dia bertanya:

```
stock > 0 ?
```

Misalnya:

```
stock = 2
```

maka:

```
2 > 0
↓
true
```

Kalau:

```
stock = 0
```

maka:

```
0 > 0
↓
false
```

Jadi:

```
stock
   ↓
dihitung
   ↓
available
```

5. Benar.

Setelah:

```
product.stock = 2
```

maka:

```
price = 500.000
stock = 2
```

sehingga:

```
500.000 × 2
=
1.000.000
```

`totalValue` adalah computed property juga.

6. Ada satu kesalahan.

Anda menjawab:

```
Keyboard
2
2
1000000
```

Padahal baris ketiga:

```
print(product.available)
```

`available` bertipe:

```
Bool
```

Jadi hasilnya bukan `2`.

Karena:

```
stock = 2

2 > 0
↓
true
```

Output lengkapnya:

```
Keyboard
2
true
1000000
```

Ini sekaligus mengenalkan tipe penting Swift:

```
Bool
```

hanya mempunyai dua nilai:

```
true
false
```

Bukan `Yes/No`, bukan `1/0`, dan bukan jumlah stok.
